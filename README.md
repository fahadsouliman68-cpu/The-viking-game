# THE VIKING — صالة بلايستيشن

تطبيق أندرويد (Kotlin + Jetpack Compose) لإدارة صالة ألعاب: أجهزة، وقت، مشروبات، بيع مباشر، سجل، صندوق وورديات.

## الأقسام (شريط سفلي)
| القسم | المحتوى |
|---|---|
| 🎮 الأجهزة | بدء "لاعبين" / "أربع لاعبين"، فتح وقت بسعر، باقات، إيقاف مؤقت، تبديل النوع، مشروبات، منبّه |
| 🛒 بيع مباشر | بيع مشروبات/بنود بدون جهاز + مبلغ حر، دفع أو دين، خصم |
| 📒 السجل | كل العمليات مجمّعة بالورديات، **تعديل/حذف أي سجل** مع سجل تعديلات، إيصال، تصدير CSV |
| 💰 الصندوق | ملخص الوردية، مصاريف، ديون وتسديدها، **إغلاق وردية**، الورديات السابقة |
| ⚙️ الإعدادات | الأسعار والتقريب والحد الأدنى، الأجهزة (إضافة/تسمية/سعر خاص)، المشروبات والمخزون، الباقات، النسخ الاحتياطي |

## أبرز ما عُولج
- السعر يُثبَّت لحظة بدء كل جزء (تغيير الإعدادات لا يؤثر على جلسة شغّالة).
- التقريب يتم مرة واحدة على مجموع الوقت لكل (نوع/سعر) + حد أدنى للجلسة قابل للضبط.
- تأكيد قبل الحساب + **تراجع لمدة دقيقة** بعد الإيقاف أو البيع.
- ورديات بدل التاريخ التقويمي (لا يتشوّه اليوم بعد منتصف الليل).
- حفظ ذرّي (ملف مؤقت ثم إعادة تسمية) + نسخة احتياطية تلقائية عند إغلاق الوردية + تصدير/استيراد JSON + تنبيه إذا مرّ يوم بلا نسخة.
- المنبّه يعمل عبر `AlarmManager` + إشعار حتى والشاشة مغلقة (يتطلب السماح بالإشعارات).
- المشروبات بسعر 0 لا يمكن إضافتها حتى يُحدَّد السعر.
- مخزون اختياري للمشروبات يُخصم تلقائياً ويُعاد عند الحذف/التراجع.

## البناء
- **Android Studio**: افتح المجلد، انتظر المزامنة، ثم Run.
- **GitHub Actions**: كل push إلى `main` يبني APK ويرفعه في تبويب Actions ← Artifacts (`TheViking-debug-apk`).
- محلياً: `gradle assembleDebug` (Gradle 8.9 + JDK 17).
